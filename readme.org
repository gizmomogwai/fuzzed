* Fuzzed
A [[https://dlang.org][D]] fuzzy-search library with an example terminal program, =fuzzed=,
similar to [[https://github.com/junegunn/fzf][fzf]].

Matching is case-insensitive subsequence filtering. Match positions identify
complete graphemes; spaces are literal parts of the pattern.

** Build and run
Use =nix develop= for the toolchain.

#+begin_src sh
dub build
dub run --config=fuzzed -- alpha alphabet beta
dub test
#+end_src

The example program accepts candidates as arguments or reads lines from stdin.
It prints the accepted candidate and requires the Kitty keyboard protocol support.

** Usage
Add the dependency with =dub add fuzzed=.
